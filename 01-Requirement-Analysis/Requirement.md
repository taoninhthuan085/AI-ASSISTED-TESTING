# Technology E-commerce Website

## Project Overview

Build a responsive technology e-commerce website that allows users to browse products, search for products, manage shopping carts, and place orders.

---

## Functional Requirements

### Product Catalog

Users shall be able to:

* View product listings.
* View product details.
* Browse products by category.
* Browse products by brand.

### Search & Filter

Users shall be able to:

* Search products by name.
* Filter products by brand.
* Filter products by category.

### Shopping Cart

Users shall be able to:

* Add products to cart.
* Remove products from cart.
* Update product quantity.
* View cart total amount.

The system shall automatically recalculate the total amount whenever the cart content changes.

### User Authentication

Users shall be able to:

* Log in.
* Log out.

### Checkout

Users shall be able to:

* Review order summary.
* Place orders successfully.

---

## Assumptions

* Product data is stored locally.
* Authentication is simulated.
* Payment integration is out of scope.

---

## Expected Features

* Product Listing
* Product Search
* Product Filter
* Shopping Cart
* Login / Logout
* Checkout
* Order Summary
