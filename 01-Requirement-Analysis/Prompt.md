# Prompt Used for AI-Generated Application

## Objective

Generate a responsive technology e-commerce website for QA testing and AI-assisted testing activities.

---

## Prompt

Act as a Senior Frontend Developer.

Build a responsive technology e-commerce website using HTML, CSS, and JavaScript.

### Functional Requirements

#### Product Catalog

Users shall be able to:

- View product listings (+8 items).
- View product details.
- Browse products by category.
- Browse products by brand.

#### Search & Filter

Users shall be able to:

- Search products by name.
- Filter products by brand.
- Filter products by category.

#### Shopping Cart

Users shall be able to:

- Add products to cart.
- Remove products from cart.
- Update product quantity.
- View cart total amount.

The system shall automatically recalculate the total amount whenever the cart content changes.

#### User Authentication

Users shall be able to:

- Log in.
- Log out.

#### Checkout

Users shall be able to:

- Review order summary.
- Place orders successfully.

---

### Non-Functional Requirements

- Responsive design for desktop and mobile devices.
- Clean and maintainable code structure.
- User-friendly interface.
- No external database required.
- Product data can be stored in JavaScript arrays or JSON objects.

---

### Sample Product Data

Include at least 8 technology products from different brands and categories.

Example categories:

- Smartphone
- Laptop
- Tablet
- Accessory

Example brands:

- Apple
- Samsung
- Dell
- Asus
- Logitech

---

### Shopping Cart Requirements

The shopping cart must support:

- Add product
- Remove product
- Increase quantity
- Decrease quantity
- Calculate subtotal
- Calculate total amount

---

### Deliverables

Generate:

- index.html
- style.css
- script.js

Use vanilla HTML, CSS, and JavaScript only.

The generated application should be functional and ready for QA testing.
